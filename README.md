# Business Idea Validator

A client-only React app that turns a one-line startup idea into a full pre-launch
validation report: market score, competitor scan, monetization ideas, MVP scope,
launch strategy, viral hooks, business model canvas, SWOT, and financial
projections — exportable as a PDF.

**This is a demo.** Report content is generated from local, deterministic
templates keyed off words in your idea text — there is no backend and no AI
model connected. See [Current limitations](#current-limitations).

## Tech stack

- React 18 + TypeScript + Vite
- Tailwind CSS (design tokens for the neo-brutalist palette/shadows/type)
- Framer Motion (page transitions, staggered reveals, the animated score ring)
- Vitest + React Testing Library
- `html2pdf.js` for client-side PDF export

## Getting started

```bash
npm install
npm run dev      # start the dev server
npm test         # run the test suite
npm run build    # type-check and build for production
```

## How it works

The app is a simple state machine (`src/App.tsx`) with four screens:

```
landing → input → analyzing → report
```

- **Landing** (`LandingPage.tsx`): hero pitch + 3-step "how it works", CTA into the form.
- **Input** (`IdeaInputForm.tsx`): a single textarea for the one-line idea.
- **Analyzing** (`AnalyzingSequence.tsx`): a staged loading sequence (cosmetic —
  no real analysis happens here).
- **Report** (`ReportPage.tsx`): sidebar-navigated, scrollspy'd report made up of
  ten section components under `src/components/sections/`, exportable to PDF.

Report content comes from `src/mock/generateReport.ts`, which scans the idea
text for keyword signals and pulls from template banks
(`src/mock/templateBanks.ts`) using a seeded RNG (`src/mock/seededRandom.ts`)
so the same idea text always produces the same report.

## Development history

This app went through three distinct phases:

**1. Initial build — "Investor Deck" design.** The original implementation
(dark navy/gold theme, Georgia serif) per
[`docs/superpowers/specs/2026-07-02-business-idea-validator-design.md`](docs/superpowers/specs/2026-07-02-business-idea-validator-design.md).
Established the whole app: state machine, mock report generator, all ten
report sections, scrollspy sidebar nav, and PDF export.

**2. Abandoned "cloud-console" restyle.** A planned light-theme/blue-accent
restyle ([spec](docs/superpowers/specs/2026-07-02-cloud-console-restyle-design.md))
got only its first step (color tokens) committed before stalling, leaving the
app in a visually broken state (styles referencing a deleted color token).

**3. Neo-brutalist rebuild.** Rather than finish the stalled restyle, the app
was fully redesigned: thick borders, hard offset shadows, a cream/lime/violet
palette, Space Grotesk + Inter type, and Framer Motion animations throughout.
Styling moved from plain CSS custom properties to Tailwind. Report content,
data flow, and component logic were left unchanged — this was a visual
rebuild only. Afterward, a landing page was added ahead of the input screen,
and the native browser `confirm()` on "Back to Start" was replaced with a
custom modal styled to match.

Run `git log --oneline` for the full commit-by-commit history.


## Current limitations

- **No AI model.** Report content is template-based, not generated by an LLM.
  The landing page says so explicitly.
- **No backend.** Everything runs client-side; nothing is persisted, and
  closing the tab loses the current report.
- **No history.** Only one report exists at a time — there's no saved list of
  past ideas to revisit or compare.

Wiring up a real LLM would need a backend or serverless function to hold the
API key (it can't be called safely straight from the browser).
